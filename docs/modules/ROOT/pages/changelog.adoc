== `2.0.0`

=== Release
- link:{github}2.0.0[GitHub]
- link:{nuget}2.0.0[NuGet]

=== Changes
- Supported targets: `.NET standard 2.0`, `.NET 8.0`, `.NET 9.0`, `.NET 10.0` and .NET full framework (explicit support for `4.6.2`, `4.7`, `4.7.1`, `4.7.2`, `4.8`, `4.8.1`)

- Initial version of documentation, available on link:{ppwcode-docs}[PPWCode .NET Docs]
